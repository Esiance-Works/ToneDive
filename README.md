# ToneDive

ToneDiveは、ギターの押弦フォームからコード候補を調べ、練習や演奏を支援するAndroidアプリです。

このリポジトリでは、ToneDiveの公開文書とアプリ更新設定を管理しています。アプリ本体のソースコードは含まれていません。

## 公開ページ

- [ToneDive 公式情報](https://esiance-works.github.io/ToneDive/)
- [プライバシーポリシー](https://esiance-works.github.io/ToneDive/privacy-policy)
- [利用規約](https://esiance-works.github.io/ToneDive/terms)

## 更新設定

`update-config.json`は、ToneDive Android版の任意更新・強制更新判定に使用する公開設定です。秘密情報、APIキー、GitHubトークンは含みません。
